# 📚 BookLoan - Library Management System

**BookLoan**  adalah sistem manajemen perpustakaan modern berbasis web yang dirancang untuk memudahkan administrasi sirkulasi buku, pendataan anggota, dan pemantauan stok inventaris secara real-time. Dibangun dengan antarmuka **Dark Mode** yang estetis dan responsif.

---

## ✨ Fitur Utama

- **📊 Dashboard Interaktif**: Ringkasan statistik total buku, anggota, buku yang sedang dipinjam, dan peringatan stok kritis.
- **🔄 Log Transaksi Real-time**: Monitoring aktivitas peminjaman dan pengembalian buku dengan indikator keterlambatan otomatis.
- **📦 Manajemen Inventaris**: Pengelolaan data buku lengkap dengan status stok (Aman, Kritis, atau Kosong).
- **📱 Responsive Design**: Antarmuka yang optimal diakses melalui desktop, tablet, maupun smartphone.
- **📄 Laporan Siap Cetak**: Fitur cetak laporan stok untuk keperluan dokumentasi fisik.
- **🔐 Sistem Autentikasi**: Hak akses khusus untuk Admin untuk menjaga keamanan data.

---

## 🛠️ Stack Teknologi

- **Backend:** PHP (Native)
- **Database:** MySQL
- **Frontend Framework:** Tailwind CSS 4.0
- **Icons & Assets:** FontAwesome 6.4.2 & Google Fonts
- **Interactivity:** Alpine.js (untuk modal & sidebar mobile)
